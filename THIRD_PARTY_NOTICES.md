# Third-Party Data Notices

The generated common-character replacement rules use the following development-time data sources:

## Unicode Unihan Database

- Source: https://www.unicode.org/Public/UCD/latest/ucd/Unihan.zip
- Used fields: `kMandarin`, `kRSUnicode`
- Terms of use: https://www.unicode.org/license.txt

## CJKVI IDS Database

- Source: https://github.com/cjkvi/cjkvi-ids
- Raw data file: `ids.txt`
- Copyright notice in the source data: Copyright (c) 2014-2017 CJKVI Database; based on CHISE IDS Database.
- Repository license: GNU General Public License v2.0

The application embeds generated offline replacement rules. It does not contact these sources at runtime.
